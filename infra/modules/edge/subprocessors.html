Metalcraft Inc uses the providers below to operate ufo. A provider processes the information described in our Privacy Policy only when its service is needed or when a member uses the related feature.

Infrastructure

  • Amazon Web Services: Compute, networking, databases, file storage, email delivery, and optional model inference through Amazon Bedrock
  • Cloudflare: Web delivery, edge security, DNS, and feature flags

AI and search

  • OpenRouter: Model routing
  • Fireworks AI and Baseten: Inference for the default hosted model
  • Anthropic, Google, Moonshot AI, and DeepSeek: Optional model inference when a workspace selects a related model
  • OpenAI: Vector embeddings and optional model inference
  • Perplexity and Exa: Web research
  • Turbopuffer: Search and memory indexing

Tools and connections

  • E2B: Isolated code and tool execution
  • Browserbase: Remote browser sessions
  • Composio and Pipedream: Account connections and actions in connected services
  • Photon (Spectrum Cloud): Delivery of iMessage messages for the iMessage surface

Accounts and operations

  • WorkOS: Authentication and account identity
  • People Data Labs: Company and role information used during onboarding
  • Stripe: Payment methods and billing management
  • Metronome: Usage metering and account balances
  • Datadog: Service monitoring, error reports, and masked web session recordings

Changes

Changes to this list appear on this page with a new update date.
