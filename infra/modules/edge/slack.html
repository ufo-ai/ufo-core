ufo is an AI assistant that answers questions and completes work from Slack messages. It keeps each conversation in its Slack thread.

What ufo does

  • Answers @ufo mentions in channels where it is present
  • Answers direct messages in the app's Messages tab
  • Reads the channel and thread context needed to answer
  • Receives files and can send files in its reply
  • Shows a Thinking… status while a request runs

ufo does not join channels on its own. After a member mentions ufo in a thread, ufo can answer later messages in that thread when they are relevant.

Permissions

  • Message history: reads the channel, direct-message, and thread context needed to answer
  • Files: receives attached files and sends result files
  • Member information: uses names and verified email addresses to identify members and enforce ufo workspace access
  • Conversation information: identifies the Slack conversation and applies its access rules
  • Message access: posts replies and progress status

ufo uses a bot token. It does not request a Slack user token.

Install ufo

  1. Sign in to a ufo workspace. If you need one, create a workspace or join the waitlist.
  2. In ufo chat, ask ufo to connect a Slack workspace.
  3. A ufo workspace admin opens the returned Add to Slack link.
  4. Review the requested permissions, choose the Slack workspace, and approve the install.

Each Add to Slack link is private, expires, and installs ufo in the Slack workspace that is linked to the ufo workspace that created it.

Use ufo

After installation, select Continue in Slack and send ufo a direct message. To use ufo in a channel, add it to the channel and mention @ufo. Replies stay in the message thread.

AI output

ufo uses large language models. Responses, summaries, and other output can be inaccurate. Review important output before you use it.
