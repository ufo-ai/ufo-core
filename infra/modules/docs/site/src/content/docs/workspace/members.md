---
title: Members and admins
description: Add or remove members, assign admins, and understand which agents each person can use.
---

Members are not billed by seat. A new member can use the agent after they join or an admin adds
them. There is no approval queue.

## Add a member

An admin can ask the agent:

> Add alex@ufo.ai as a member and send the sign-in email.

> Add pat@contractor.example as an admin. Do not notify them.

An admin can also use **Add member** on the **Team** page. Turn **Notify** off for a silent add.

A teammate on the workspace's email domain can sign in and join directly. A person on another
domain must be added by their exact address.

## Admins

A workspace can have several admins. Admins can manage members and roles, connect Slack, fill
workspace credential controls, handle billing, and open every agent.

Any member can ask who is in the workspace and which members are admins. An admin can ask the agent
to change a role. A workspace must keep at least one active admin, so the last admin cannot be
demoted.

## Agent access

Non-admin members can use:

- Agents open to the workspace.
- Agents they created.
- Private agents shared with them.

Share or remove access from the private agent's own conversation.

## Remove and restore access

An admin can ask the agent to remove a member. The agent stops answering that member, and their
running turn stops before its next step.

The member's conversation history and memory remain. Add the member again to restore access.
