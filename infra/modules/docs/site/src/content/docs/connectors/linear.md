## Connect Linear

Ask the agent:

> Connect my Linear account.

Open the private authorization control and approve the Linear workspace. The connection follows
your access to teams, projects, and issues.

## What ufo can do

- Search issues and read their details.
- Read teams, projects, cycles, labels, and workflow states.
- Create issues and comments.
- Update status, assignee, project, or other fields when requested.

State the team, project or cycle, filters, and allowed writes.

> Review open Engineering issues in the current cycle. List blocked work, missing owners, and
> issues with no recent update. Do not change Linear.

## Fix Linear access

Confirm that the connected account can see the team and project. Reconnect if access expired. If
search results are too broad, give the exact team, state, label, or issue identifier.
