---
title: Applications
description: How an application is created, who can use it, and what you approve before it exists.
---

Ask the agent for an application and it builds one.

Name the job it is for and the agent goes straight to an interview: what job the application is
for, and who can use it. Name nothing and you get a guided build — the same run with a proposal in
front of it.

Either way you are shown the homepage design, and creation follows only once you accept it.

Choose whether the application is yours alone or open to everyone in the workspace. A shared
application's own homepage screen stays limited to its owner and the workspace's admins.
