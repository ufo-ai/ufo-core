---
title: Scheduled work
description: Recurring tasks, notifications, and reminders — how they run, when they post, and where to read what they did.
---

Ask for a recurring task, a notification, or a reminder, and the agent runs it on a repeating
schedule.

A run posts only when it finds something worth reporting. A quiet run says nothing.

Every schedule repeats. There is no one-time reminder; a schedule that should stop can carry an
expiry instead.

## Reading and changing them

Tasks, in the web portal's sidebar, lists the runs of recurring tasks and source triggers, newest
first. A run opens its transcript, and a running one can be stopped.

The Tasks tab on the Workspace page holds the tasks and the triggers themselves. It pauses and
resumes a task and edits or deletes a row. Asking the agent to change one does the same thing.

Radar, also in the sidebar, opens each scheduled run as a full report with its files and its
conversation.
