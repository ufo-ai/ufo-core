---
title: Not available yet
description: Four things a workspace may reasonably expect that ufo does not do today, and what to do instead.
---

- **A one-off top-up.** Credit is added by an automatic refill rule, which stays in place until it
  is turned off. Adding credit once, leaving no rule behind, is not something the billing screen or
  the agent can do.
- **Invitations you issue.** A workspace cannot invite another company. Only the ufo team issues
  invitations.
- **A second workspace on one email domain.** One workspace exists per email domain, and a
  colleague signing in with the same domain joins the existing one.
- **A one-time reminder.** Every scheduled task repeats. A schedule that should stop can carry an
  expiry.

Ask the agent to pass any of these to the team.
