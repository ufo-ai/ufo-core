---
title: Memory
description: What the agent remembers across conversations, the three scopes memory is held in, and how to correct a fact.
---

The agent remembers durable facts across conversations. Memory is held in three scopes:

- **Your private memory**, searchable only in your own conversation.
- **Shared workspace memory**, available across the workspace. In a shared channel, this is what is
  searched.
- **Room-scoped memory.** A private channel or group DM carries a scope of its own alongside the
  shared one.

A channel shared with an outside organization is sealed. Nothing said there reaches shared workspace
memory, and nothing from shared memory is recalled into it. You still reach your own private memory
there, and what you say there stays in the channel rather than joining that private memory.

No memory crosses between workspaces.

## Reading and correcting

Memory in the web portal lists the facts saved about you and your workspace. Record a correction
there and it supersedes the earlier statement. Stating the correction in chat does the same.
