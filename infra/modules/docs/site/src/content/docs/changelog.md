## September 10, 2026

- 🧑‍💻 **Bring your own Coding seat** — code with your ChatGPT subscription in UFO.
- 🤏 **New context compaction replaces summarization** — cuts tokens and latency by more than 10x.
- 🧑‍🧑‍🧒 **Pick any chat's model** — Claude, GPT, and GLM families, switchable mid-thread.
- 🔄 **Trigger automatically** — tell UFO what to do on a new pull request, Granola transcript, or
  a triggered Datadog monitor.
- 🗣 **Bring UFO into Slack** — tag `@ufo` for your personal and company context, fully
  permissioned.
- 🧠 **Import from GBrain** — sync your existing company brain to UFO.
- ⌨ **New terminal agent** — install once on Mac, Linux, or Windows with
  `curl -fsSL https://ufo.ai/ufo | sh`.
- 🌐 **Browse the web for you** — UFO visits websites, fills in forms, and downloads files.
- 🔌 **Connect the tools you already use** — Slack, Gmail, GitHub, Linear, HubSpot, Stripe, GBrain,
  and many more.
- 🧵 **UFO remembers** — keep useful preferences, decisions, and project details available across
  conversations.
- 📄 **File artifacts** — create Word documents, Excel spreadsheets, PowerPoint decks, PDFs, and
  more.
