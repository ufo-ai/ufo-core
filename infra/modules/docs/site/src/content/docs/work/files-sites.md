Attach files to a conversation when they are inputs to the task. State what the agent must read,
change, or produce.

> Check the attached forecast for inconsistent totals. Fix the formulas and return the corrected
> spreadsheet with a short list of changes.

## Files the agent creates

The agent can create and return reports, spreadsheets, slide decks, PDFs, and documents. A file is
delivered only when the agent shares it in the conversation. A path inside its working computer is
not a delivered file.

Ask for the file format and any layout requirements in the request. Ask the agent to verify the
rendered result when page layout or visual quality matters.

## Hosted sites

For a website, dashboard, or interactive tool, the agent returns a hosted link instead of a file.
State who needs access and whether the site needs durable data or a backend.

> Build a private project status dashboard from the attached CSV. Include filters for owner and
> status. Verify it at desktop and phone widths and share the hosted link.

## Find an earlier result

Open **Artifacts** in the web portal. It lists files and hosted sites shared with the workspace.
