---
title: Getting good results
description: Set authority, correct work, and require evidence.
---

Start with [Ask for work](/getting-started/ask/).

## State authority

Use direct boundaries such as “do not send,” “do not merge,” or “production is read-only.” If the
agent may publish or change external state, name the exact system and action.

## Correct the course

Continue in the same conversation when new context affects the result. State what is wrong, provide
the missing fact, and name the revised outcome. Start a new conversation for unrelated work.

## Ask for evidence

Request sources for factual claims and a rendered check for visual output. Ask the agent to state
when a fact is missing. Do not let it replace the fact with an assumption.

Use [Recipes](/recipes/) for complete requests you can adapt.
