An application is an agent for a repeated job. It has its own purpose, conversations, connections,
knowledge, schedule, and homepage.

Ask the main agent to create one:

> Build an application that prepares a brief before every customer meeting. It should use our
> calendar, CRM, and shared customer notes. Everyone in the workspace can use it.

## The creation flow

1. The agent asks what job the application must do and who can use it.
2. It identifies the connections, sources, and schedule the job needs.
3. It shows the proposed homepage.
4. You approve the design.
5. The agent creates the application and reports the result.

If you do not name a job, the agent proposes an application and then uses the same interview.
Creation starts only after you approve the homepage.

## Visibility

Choose a private application or one that every workspace member can use. A shared application's own
homepage settings remain limited to its owner and workspace admins.

Admins can open every application. Other members can open workspace applications, applications they
created, and private applications shared with them.

## Change an application

Open the application's conversation and ask for the change. Use that conversation to add a source,
connect an account, change its schedule, revise its homepage, or share it with another member.

## Workspace applications

ufo includes focused applications for common work:

- **Chat** holds workspace conversations and starts new work.
- **Code** reviews changed pull requests and can keep approved pull requests moving through checks.
- **Issues** assigns and plans new issues, and can implement issues that you approve.
- **Meetings** prepares briefs and can record follow-ups and decisions.
- **Metrics** reports delivery, revenue, runway, reliability, product, and support measures from the
  accounts you connect.
- **Notifications** decides which events from your agents need your attention.
- **Wiki** presents workspace knowledge, decisions, and member information on one page.

See [Build an internal application](/recipes/internal-application/) for a complete example.
