---
title: iMessage
description: Connect a phone and work with the agent from iMessage.
---

An admin must make the first iMessage connection for the workspace. After that, each member can
connect their own phone.

Ask the agent to start the connection:

> Connect my phone to iMessage.

Complete the private connection step that the agent returns. Do not send a code or credential in
the chat.

Use iMessage for short requests and updates when you are away from the web portal. Use the web
portal for large files, long reports, task management, and workspace settings.

If your phone is no longer connected, ask the agent to check the connection and start a new handoff.
