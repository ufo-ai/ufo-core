---
title: Build a monthly board pack
description: Create and verify a recurring presentation and PDF from current company sources.
---

## Connect the source systems

Connect the systems that hold revenue, product use, delivery, customer, hiring, and cash data. Add
the operating plan and prior board packs as synced sources. Name one source of truth for each figure.

Build one pack by hand before you schedule it. Approve the section order, visual rules, definitions,
and checks. Keep the approved deck as the layout reference for later runs.

## Create the scheduled task

> At 7:00 AM Pacific time on the first day of each month, prepare the board pack for the previous
> complete month. Use the approved deck as the layout reference. Include company progress, product
> use, revenue, cash and runway, customer movement, delivery, hiring, risks, and the next six weeks.
> Use only figures from connected sources. Reconcile revenue and cash with their source reports,
> label estimates and missing data, and link each figure in the notes. Compare every measure with
> the prior month and plan. Keep each slide to one point. Render and inspect every slide for clipped
> text, unreadable charts, and inconsistent totals. Return the editable PPTX and PDF in this
> conversation. Do not send or publish them.

## Review each run

Each run has its own conversation and files. A local file path is not delivery; both files must be
shared in the run.

Use the same conversation to request corrections. Change the scheduled task only when the rule must
apply to later months. A one-month exception belongs in that run, not in the durable prompt.
