---
title: Files and hosted sites
description: How the agent hands back reports, spreadsheets, slide decks, and documents, and how a site it builds is served.
---

The agent produces reports, spreadsheets, slide decks, PDFs, and documents, and shares them back as
files you can download. A file you cannot see is not delivered, so the agent shares the file rather
than naming a path to it.

A website is different: the agent hosts it and shares a permanent link instead of a file to
download.

Artifacts, in the web portal's sidebar, lists the shared files and the hosted sites of your
workspace.
