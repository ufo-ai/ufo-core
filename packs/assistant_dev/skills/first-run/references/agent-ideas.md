# Agent ideas, by what the team uses

Match the member's tools to the rows below, take 5 to 15 ideas, and offer them in the member's own
words. An app they name that is not listed takes the class of the closest one — the rows are keyed
by class, not by brand, so a team on Shortcut and Front reads as tracker + support.

## Nothing to match

Where they picked nothing, or nothing they picked can be reached, offer work that needs no account:

| Agent | What it does |
| --- | --- |
| competitor-watch | Tracks named competitors and writes up what changed. |
| market-researcher | Researches a market, a company, or a person on request. |
| writing-desk | Drafts the recurring note — the update, the announcement, the post. |
| meeting-notes | Turns pasted notes or a transcript into decisions and owners. |

`daily-brief` already exists in every workspace. Name it as something they already have when
nothing else fits. Never propose creating it.
