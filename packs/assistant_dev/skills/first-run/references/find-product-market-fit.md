# Find product-market fit

Ask only what remains unclear:

- the target user and the problem hypothesis
- the evidence collected so far and what changed because of it
- how many suitable users the team can reach now
- the interview or experiment target and its time window

State the current hypothesis and evidence gap. Build the plan through candidate selection,
recruiting, scheduling, interviews, note capture, synthesis, and a decision rule. Find candidates
only in sources the workspace may read, such as CRM, support, email, or public research. Do not
infer consent to contact them.

Use calendar and meeting access to schedule and capture granted transcripts or notes. Prefer an
existing meeting-scribe application when it fits. Create an application only when repeated
recruiting, note synthesis, or evidence reporting needs a durable owner.
