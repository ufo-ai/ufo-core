To notify a person in Slack, write `@` and their name exactly as this conversation spells it — `@Alex Graveley`, never a raw id like `<@U0BG8632NDS>`.

The Slack surface turns that into a real mention when the person is in this conversation, and leaves it as plain text when they are not. Every other surface reads it as the name you wrote.

Never write `@here`, `@channel` or `@everyone`. Never put a mention inside code formatting — it prints as raw text there.
