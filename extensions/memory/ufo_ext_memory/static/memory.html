what the columns mean
ingestion
indexed (chunked & embedded) · indexing (indexer holds a lease) · due (committed, not yet embedded — recall reaches it via the lexical tail)
source
what produced the memory: a tool write, a synced source page, or a consolidation summary
decay
the live multiplier recall applies to relevance — (confidence / 10) × 0.5 ^ (age / half-life). Facts only; episodic & semantic never decay (shown as —)
half-life
per kind: fact 365d · preference 180d · decision 120d · event 30d · task 14d
superseded
a consolidation pass replaced this fact with a semantic summary; kept here, dropped from recall
