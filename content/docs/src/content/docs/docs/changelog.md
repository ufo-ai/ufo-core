## September 10, 2026

- **ChatGPT subscription for coding** — use your subscription in ufo.
- **Context compaction** — context compaction replaces summarization. It reduces token use and
  latency by more than 10 times.
- **Select a model for each chat** — use Claude, GPT, or GLM models. You can change the model during
  a thread.
- **Automatic triggers** — start work from a new pull request, Granola transcript, or Datadog
  monitor trigger.
- **Slack** — tag `@ufo` to use personal and company context with its permissions.
- **GBrain import** — sync an existing company brain to ufo.
- **Terminal UFO** — install on Mac, Linux, or Windows with
  `curl -fsSL https://ufo.ai/ufo | sh`.
- **Browser** — visit websites, fill in forms, and download files.
- **Connections** — connect Slack, Gmail, GitHub, Linear, HubSpot, Stripe, and GBrain.
- **Memory** — keep preferences, decisions, and project details available across
  conversations.
- **Files** — create Word documents, Excel spreadsheets, PowerPoint decks, and PDFs.
