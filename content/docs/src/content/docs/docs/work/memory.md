---
title: Knowledge and memory
description: Understand what your UFO remembers, where a fact is visible, and how to correct it.
---

Memory keeps facts that remain useful across conversations, such as preferences and decisions.

## Memory scopes

- **Private memory** is available only in your conversations.
- **Workspace memory** is available across the workspace. Shared channels use this scope.
- **Room memory** belongs to a private channel or group direct message.

These scopes control how agents use memory. Workspace admins can export all members' private
memory. See [Data ownership](/docs/work/data-ownership/).

No memory crosses between workspaces.

An externally shared channel is sealed from workspace memory. Facts from the channel stay in that
channel, and workspace facts do not enter it. Your own private memory is still available to you.

## Add a fact

State the fact and the scope:

> Remember for me that I prefer weekly reports with a short summary and a table of blocked work.

> Remember for the workspace that the product release review happens every Thursday.

Use a synced source for documents and records that change. Use memory for a durable fact or
preference.

## Read and correct memory

Open **Memory** in the web portal to read saved facts. Record a correction there, or state it in
chat:

> Correct the workspace memory: the release review is now on Wednesday.

The correction supersedes the earlier fact.

## When a detail is missing

Check where the fact was first stated. A private room, an external shared channel, and a workspace
conversation have different scopes. Restate the fact in the required scope.
